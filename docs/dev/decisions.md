## 아직 정해지지 않은 것

- 자동 업데이트를 할지(조정자 추천: 알리기만).
- 받은 설치 파일의 확인 수준(조정자 추천: 우선 체크섬만).
- 거래소 시각이 없는 시세로 모의 체결을 할지(조정자 추천: 하지 않는다).
- 승인을 거절해 막힌 매매에 새 승인 번호를 붙일 수 있게 둘지(조정자 추천: 잠근다).
- 모의계좌의 수수료율 · 미끄러짐 · 반올림 방향 등 확인되지 않은 숫자의 실제 값.
