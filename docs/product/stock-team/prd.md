# 주식 투자 에이전트 팀 기획 PRD

> 기준 문서: [기획 PRD](prd.md) · [기획 상세 스펙](spec.md) · [유저 플로우](flow.md)

## 왜 지금

나는 투자를 잘 모르고, 장 중에 시세를 볼 시간이 없다.
매매할 때 감정에 휘둘리고, 같은 실수를 반복한다.
근거: 본인 답변 "투자를 잘모름", "시간이 없음" (2026-11-14)
근거: 본인 답변 "감정 매매", "같은 실수 반복" (2026-11-14)
근거: 횟수와 시간 같은 숫자는 없다 (가정)

## 페르소나

### <a id="p1"></a>P1 바빠서 장을 못 보는 초보 투자자

쓰는 곳: [R1](#r1) · [R2](#r2) · [R3](#r3) · [R4](#r4) · [R5](#r5) · [R6](#r6) · [R7](#r7) · [R8](#r8) · [R9](#r9) · [R10](#r10) · [R11](#r11) · [R12](#r12) · [R13](#r13) · [R14](#r14) · [R15](#r15) · [R16](#r16) · [F1](spec.md#f1) · [F2](spec.md#f2) · [F3](spec.md#f3) · [F4](spec.md#f4) · [F5](spec.md#f5) · [F6](spec.md#f6) · [F7](spec.md#f7) · [F8](spec.md#f8) · [F9](spec.md#f9)

회사에 다니며 장 중에는 시세를 거의 못 보는 나 자신이다.

원하는 것
- 내가 안 봐도 원칙대로 알아서 굴러가면 좋겠다.
- 투자를 잘 몰라도 팀이 왜 샀는지는 알고 싶다.
- 한도를 넘거나 이상할 때만 나에게 물어봤으면 좋겠다.
- 사무실에서 팀이 논의하며 일하는 모습을 보고 싶다.

행동 패턴
- 장 중에는 회사에서 일하고 폰으로 가끔 확인한다.
- 퇴근 후에 몰아서 본다.
- 뉴스나 커뮤니티를 보고 산다.
- 떨어져도 못 판다.
- 아직 투자를 거의 하지 않는다.

## 요구사항

### <a id="r1"></a>R1 투자 팀은 담당별로 일하고 일이 생기면 관련 담당에게 넘겨 논의한다

쓰는 곳: [F2](spec.md#f2)

누구: [P1](#p1)
근거: [BR1](#br1)
우선순위: P1
왜: 내가 안 봐도 원칙대로 알아서 굴러가면 좋겠다.

완성 기준
- <a id="r1-1"></a>R1-1 팀에는 뉴스 공시 시세, 전략, 리스크, 복기, 매매 담당과 팀장이 있다.
- <a id="r1-2"></a>R1-2 뉴스나 공시나 시세에 일이 생기면 담당이 관련 담당에게 넘긴다.
- <a id="r1-3"></a>R1-3 넘겨받은 담당들이 논의하고 팀장이 최종 판단을 내린다.
- <a id="r1-4"></a>R1-4 팀장이 사기로 하면 매매 담당이 주문을 낸다.

### <a id="r2"></a>R2 투자 팀은 내 컴퓨터에서 하루 종일 쉬지 않고 돈다

근거: [BR2](#br2)
우선순위: P1
왜: 장 중에는 회사에서 일하고 폰으로 가끔 확인한다.

완성 기준
- <a id="r2-1"></a>R2-1 컴퓨터를 켜 두면 내가 아무것도 하지 않아도 팀이 계속 일한다.
- <a id="r2-2"></a>R2-2 컴퓨터가 다시 켜지면 팀이 하던 일을 이어서 한다.

### <a id="r3"></a>R3 투자 팀은 손익과 상황에 따라 알아서 사고팔고 쉬었다가 다시 시작한다
