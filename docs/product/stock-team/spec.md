# 주식 투자 에이전트 팀 기획 상세 스펙

> 기준 문서: [기획 PRD](prd.md) · [기획 상세 스펙](spec.md) · [유저 플로우](flow.md)

## 상태표

| 대상 | 상태 | 뜻 |
|---|---|---|
| 투자 팀 | 운용 중 | 팀이 매매하는 날이다 |
| 투자 팀 | 쉬는 중 | 팀장이 오늘은 매매를 쉬기로 한 날이다 |
| 투자 팀 | 하루 한도 멈춤 | 하루 손실 한도에 닿아 그날 새로 사지 않고 다음 거래일에 다시 시작한다 |
| 투자 팀 | 이상 감지 멈춤 | 시세 지연이나 오류로 새 주문만 멈추고 풀리면 다시 시작한다 |
| 투자 팀 | 전체 정지 | 최대 손실에 닿아 모두 멈추고 내가 확인해야 다시 시작한다 |
| 매매 | 논의중 | 담당들이 살지 팔지 논의하고 있다 |
| 매매 | 판단됨 | 팀장이 사기로 또는 사지 않기로 정했다 |
| 매매 | 승인대기 | 금액 한도를 넘어 내 승인을 기다린다 |
| 매매 | 막힘 | 원칙이나 근거가 부족해 나가지 못했다 |
| 매매 | 주문됨 | 매매 담당이 주문을 냈다 |
| 매매 | 보유중 | 사서 가지고 있다 |
| 매매 | 팔림 | 손절이나 익절이나 청산으로 팔았다 |
| 매매 | 복기됨 | 복기 담당이 돌아보고 기록했다 |
| 템플릿 | 모의중 | 모의계좌에서 돌고 있다 |
| 템플릿 | 승격대기 | 기준을 통과해 내 실전 승인을 기다린다 |
| 템플릿 | 실전중 | 실제 계좌에서 돌고 있다 |
| 템플릿 | 멈춤 | 쓰지 않도록 멈췄다 |
| 규칙 개선안 | 제안됨 | 복기 담당이 내고 내 승인을 기다린다 |
| 규칙 개선안 | 냉각중 | 위험을 키우는 변경이라 승인 뒤 기다리는 중이다 |
| 규칙 개선안 | 반영됨 | 규칙에 들어갔다 |
| 규칙 개선안 | 거절됨 | 내가 거절했다 |

## 조건표

| 조건 | 갈래 | 정해지는 곳 |
|---|---|---|
| 장이 열려 있는가 | 예, 아니오 | 거래소 정규장 시간이면 예다 |
| 오늘 판단 | 매매, 쉬기 | 팀장이 그날 시장 상황을 보고 정한다 |
| 종목 판단 | 사기, 팔기, 지켜보기 | 팀장이 담당들의 논의를 듣고 정한다 |
| 근거가 다 있는가 | 예, 아니오 | 가설과 계기와 들어간 값과 손절값과 목표값이 다 있으면 예다 |
| 원칙을 지키는가 | 예, 아니오 | 자동 규칙이 기본 원칙 16개로 확인한다 |
| 금액 한도 안인가 | 안, 넘음 | 템플릿의 자동 주문 금액 한도와 비교한다 |
| 내 답 | 승인, 거절, 답 없음 | 내가 폰이나 사무실에서 누른다 |
| 하루 손실 한도에 닿았는가 | 예, 아니오 | 그날 손실을 템플릿 한도와 비교한다 |
| 최대 손실에 닿았는가 | 예, 아니오 | 계좌 최고점 대비 손실을 템플릿 한도와 비교한다 |
| 자료와 연결이 정상인가 | 예, 아니오 | 시세 지연과 오류와 계좌 불일치가 없으면 예다 |
| 계좌 종류 | 모의, 실전 | 템플릿이 도는 계좌로 정해진다 |
| 템플릿이 기준을 통과했는가 | 예, 아니오 | 표본 수와 기간과 손익과 최대 손실 기준과 비교한다 |
| 합의 점수가 기준을 넘는가 | 예, 아니오 | 담당들이 매긴 점수를 합쳐 템플릿 기준과 비교한다 |
| 등록된 내 기기인가 | 예, 아니오 | Tailscale에 내가 등록한 기기면 예다 |
| 6자리가 맞는가 | 예, 아니오 | 인증 앱의 지금 코드이고 전에 쓰지 않은 코드면 예다 |
| 개선안이 위험을 키우는가 | 예, 아니오 | 한도를 넓히거나 손절을 넓히는 변경이면 예다 |

## <a id="f1"></a>F1 · 하루 운용 시작과 쉬기 · [R2](prd.md#r2), [R3](prd.md#r3)

| 항목 | 내용 |
|---|---|
| 목적 | 팀이 매일 스스로 매매할지 쉴지 정하고 멈춤에서 다시 시작한다 |
| 행위자 | [P1](prd.md#p1) |
| 시작 | 거래일 아침에 팀장이 하루를 시작한다 |
| 사전 조건 | 내 컴퓨터가 켜져 있고 팀이 돌고 있다 |
| 기본 흐름 조건 | 투자 팀 상태: 쉬는 중, 장이 열려 있는가: 예, 자료와 연결이 정상인가: 예, 오늘 판단: 매매 |
| 성공 결과 | 투자 팀이 운용 중으로 하루를 보내고 장이 끝나면 쉬는 중으로 돌아간다 |
| 실패 시 보장 | 멈춤 상태에서는 새로 사는 주문이 나가지 않는다 |

### 기본 흐름

- 1. 거래일 아침에 팀장이 하루를 시작한다
- 2. 팀장이 지난 상태와 자료와 연결을 확인한다
- 3. 팀장이 시장 상황을 보고 오늘 판단을 정한다
- 4. 투자 팀이 쉬는 중에서 운용 중으로 바뀐다
- 5. 담당들이 각자 방에서 사무실 자기 자리로 출근한다
- 6. 사무실 화면에 오늘 운용을 시작한 이유가 보인다
- 7. 장이 끝나면 투자 팀이 운용 중에서 쉬는 중으로 바뀐다
- 8. 담당들이 각자 방으로 돌아가 침대에서 잔다

### 대안 흐름

- 1a. 장이 열려 있는가: 아니오
  - 1a1. 투자 팀은 쉬는 중으로 남는다
  - 1a2. 끝난다
- 2a. 투자 팀 상태: 하루 한도 멈춤
  - 2a1. 투자 팀이 하루 한도 멈춤에서 쉬는 중으로 바뀐다
  - 2a2. 3으로 돌아간다
- 2b. 투자 팀 상태: 이상 감지 멈춤
  - 2b1. 자료와 연결이 정상인지 다시 확인한다
  - 2b2. 2로 돌아간다
- 2c. 투자 팀 상태: 전체 정지
  - 2c1. 사무실 화면에 내 확인이 필요하다고 보인다
  - 2c2. [FN2](#fn2) 내 승인 기다리기를 따른다
- 2d. 자료와 연결이 정상인가: 아니오
  - 2d1. 투자 팀이 쉬는 중에서 이상 감지 멈춤으로 바뀐다
  - 2d2. 나에게 이상 상황 알림이 간다
  - 2d3. 끝난다
- 3a. 오늘 판단: 쉬기
  - 3a1. 사무실 화면에 오늘은 쉬는 이유가 보인다
  - 3a2. 투자 팀은 쉬는 중으로 남는다
  - 3a3. 담당들은 각자 방 침대에서 잔다
  - 3a4. 끝난다
- 4a. 투자 팀 상태: 운용 중
  - 4a1. 장 중에 하루 손실 한도에 닿았는가가 예가 되면 투자 팀이 운용 중에서 하루 한도 멈춤으로 바뀐다
  - 4a2. 그날은 새로 사지 않고 파는 것만 한다
  - 4a3. 끝난다

### 예외 흐름

- 1b. 컴퓨터가 꺼졌다가 다시 켜진다
  - 1b1. 팀이 꺼지기 전 상태와 하던 일을 이어서 한다
  - 1b2. 2로 돌아간다

## <a id="f2"></a>F2 · 일이 생겨 팀이 논의하고 판단 · [R1](prd.md#r1), [R8](prd.md#r8), [R12](prd.md#r12)

| 항목 | 내용 |
|---|---|
| 목적 | 일이 생기면 관련 담당들이 자료를 보고 논의해 팀장이 종목 판단을 낸다 |
| 행위자 | [P1](prd.md#p1) |
| 시작 | 뉴스나 공시가 뜨거나 시세가 조건에 닿거나 정해진 시간이 되거나 재무나 거시 자료가 바뀐다 |
| 사전 조건 | 투자 팀이 돌고 있다 |
| 기본 흐름 조건 | 자료와 연결이 정상인가: 예, 합의 점수가 기준을 넘는가: 예, 종목 판단: 사기 |
| 성공 결과 | 팀장의 종목 판단과 담당별 점수와 근거가 매매 기록에 남는다 |
| 실패 시 보장 | 자료가 모자라면 사거나 팔지 않는다 |

### 기본 흐름

- 1. 뉴스 공시 시세 담당이 계기를 알아차린다
- 2. 담당이 실시간 시세와 거래량과 재무제표와 거시경제 지표와 뉴스 공시를 가져온다
- 3. 담당이 계기와 자료를 관련 담당에게 넘긴다
- 4. 넘겨받은 담당들이 비슷했던 지난 매매와 복기를 꺼내 본다
- 5. 전략 담당은 살지 팔지 의견을 내고 리스크 담당은 한도와 비중 의견을 내며 논의한다
- 6. 담당마다 점수와 근거를 낸다
- 7. 매매가 논의중에서 판단됨으로 바뀐다
- 8. 팀장이 합의 점수를 보고 종목 판단을 정한다
- 9. 가설과 계기와 들어간 값과 손절값과 목표값과 자료를 알게 된 시각이 내 컴퓨터의 매매 기록에 남는다

### 대안 흐름

- 2a. 자료와 연결이 정상인가: 아니오
  - 2a1. 가져오지 못한 자료와 이유가 남는다
  - 2a2. 투자 팀이 운용 중에서 이상 감지 멈춤으로 바뀐다
  - 2a3. 끝난다
- 8a. 합의 점수가 기준을 넘는가: 아니오
  - 8a1. 팀장이 지켜보기로 정한다
  - 8a2. 9로 돌아간다
- 8b. 종목 판단: 팔기
  - 8b1. 보유 종목 팔기 흐름으로 넘어간다
  - 8b2. 끝난다
- 8c. 종목 판단: 지켜보기
  - 8c1. 지켜보는 이유와 다시 볼 조건이 남는다
  - 8c2. 9로 돌아간다

### 예외 흐름

- 5a. 담당 하나가 답하지 못한다
  - 5a1. 팀장이 지켜보기로 정한다
  - 5a2. 9로 돌아간다

## <a id="f3"></a>F3 · 사기 주문 내기 · [R9](prd.md#r9), [R6](prd.md#r6), [R4](prd.md#r4), [R14](prd.md#r14)

| 항목 | 내용 |
|---|---|
| 목적 | 팀장이 사기로 한 종목을 원칙 안에서 주문해 보유한다 |
| 행위자 | [P1](prd.md#p1) |
| 시작 | 팀장의 종목 판단이 사기로 정해진다 |
| 사전 조건 | 매매에 팀장의 판단과 담당별 근거가 남아 있다 |
| 기본 흐름 조건 | 계좌 종류: 모의 |
| 성공 결과 | 종목을 보유하고 산 이유가 쉬운 말로 보인다 |
| 실패 시 보장 | 점검을 통과하지 못한 주문은 나가지 않는다 |

### 기본 흐름

- 1. 매매 담당이 주문 안을 만든다
- 2. [FN1](#fn1) 주문 전 점검을 따른다
- 3. 매매가 판단됨에서 주문됨으로 바뀐다
- 4. 모의계좌에서 주문이 체결된다
- 5. 매매가 주문됨에서 보유중으로 바뀐다
- 6. 사무실과 폰에 산 이유가 쉬운 말로 보인다

### 대안 흐름

- 2a. 점검에서 근거나 원칙에 걸려 주문이 막힌다
  - 2a1. 매매가 판단됨에서 막힘으로 바뀐다
  - 2a2. 사무실과 폰에 막힌 이유가 보인다
  - 2a3. 끝난다
- 2b. 점검에서 금액 한도를 넘어 내 승인을 기다린다
  - 2b1. 매매가 판단됨에서 승인대기로 바뀐다
  - 2b2. 승인되거나 한도 안으로 줄여지면 매매가 승인대기에서 주문됨으로 바뀐다
  - 2b3. 4로 돌아간다
- 4a. 계좌 종류: 실전
  - 4a1. 증권사 계좌로 주문이 나간다
  - 4a2. 5로 돌아간다

### 예외 흐름

- 4b. 정한 시간 안에 일부만 체결된다
  - 4b1. 체결되지 않은 부분을 취소한다
  - 4b2. 5로 돌아간다
- 4c. 정한 시간 안에 하나도 체결되지 않는다
  - 4c1. 주문을 취소하고 체결되지 않은 이유가 남는다
  - 4c2. 끝난다
- 4d. 증권사 주문이 실패한다
  - 4d1. 투자 팀이 운용 중에서 이상 감지 멈춤으로 바뀐다
  - 4d2. 나에게 이상 상황 알림이 간다
  - 4d3. 끝난다

## <a id="f4"></a>F4 · 보유 종목 팔기와 멈춤 · [R3](prd.md#r3), [R4](prd.md#r4)

| 항목 | 내용 |
|---|---|
| 목적 | 손익과 상황에 따라 보유 종목을 팔고 손실이 한도에 닿으면 멈춘다 |
| 행위자 | [P1](prd.md#p1) |
| 시작 | 손절값이나 목표값에 닿거나 팀장이 팔기로 정하거나 최대 보유 기간이 지난다 |
| 사전 조건 | 팔 종목을 보유하고 있다 |
| 기본 흐름 조건 | 하루 손실 한도에 닿았는가: 아니오, 최대 손실에 닿았는가: 아니오 |
| 성공 결과 | 종목을 팔고 판 이유와 손익이 쉬운 말로 보인다 |
| 실패 시 보장 | 멈춤 상태에서도 손절은 계속된다 |

### 기본 흐름

- 1. 매매 담당이 파는 계기를 알아차린다
- 2. 매매 담당이 파는 주문 안을 만든다
- 3. [FN1](#fn1) 주문 전 점검을 따른다
- 4. 주문이 체결된다
- 5. 매매가 보유중에서 팔림으로 바뀐다
- 6. 사무실과 폰에 판 이유와 손익이 쉬운 말로 보인다
- 7. 자동 규칙이 그날 손실과 계좌 최고점 대비 손실을 다시 계산한다

### 대안 흐름

- 1a. 손절값에 닿았다
  - 1a1. 논의 없이 바로 파는 주문 안을 만든다
  - 1a2. 3으로 돌아간다
- 7a. 하루 손실 한도에 닿았는가: 예
  - 7a1. 투자 팀이 운용 중에서 하루 한도 멈춤으로 바뀐다
  - 7a2. 그날은 새로 사지 않고 파는 것만 한다
  - 7a3. 나에게 멈춤 알림이 간다
  - 7a4. 끝난다
- 7b. 최대 손실에 닿았는가: 예
  - 7b1. 투자 팀이 운용 중에서 전체 정지로 바뀐다
  - 7b2. 새 매매를 모두 멈추고 걸어 둔 손절값에 닿을 때만 판다
  - 7b3. 나에게 큰 손실 알림이 간다
  - 7b4. [FN2](#fn2) 내 승인 기다리기를 따른다

### 예외 흐름

  - 1a4. 사용자가 다시 시작을 눌러야 팀이 돈다
